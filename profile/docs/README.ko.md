**LetKite는 AI와 여러분의 머신 사이를 잇는 실행 계층입니다.** 로봇이 AI에게 물리 세계의 손을 준다면, LetKite는 디지털 세계의 손을 줍니다. LetKite는 원격 MCP 게이트웨이로, Claude를 비롯한 MCP 호환 AI 어시스턴트가 서버, 공장 설비, 스마트홈 기기로 이루어진 전체 플릿에서 명령을 실행하고, 파일을 관리하고, 로그를 추적할 수 있게 해 줍니다. 이미 사용 중인 AI 요금제에 사용자 지정 커넥터로 한 번만 추가하면, 모든 작업은 권한으로 통제되고, 중요한 작업은 승인을 거치며, 감사를 위해 기록됩니다. 무료 오픈 소스인 [LetKite Lite](https://github.com/letkite/letkite-lite)로 시작하거나 [letkite.com](https://letkite.com)에서 자세히 알아보세요.
