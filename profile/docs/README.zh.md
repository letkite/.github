**LetKite 是 AI 与你的机器之间的执行层。** 机器人让 AI 在物理世界中拥有双手；LetKite 让它在数字世界中拥有双手。它是一个远程 MCP 网关，让 Claude 以及其他兼容 MCP 的 AI 助手能够在整个服务器、工厂设备和智能家居设备集群上执行命令、管理文件、跟踪日志。只需在你现有的 AI 订阅方案中把它添加为一次自定义连接器，此后每一次操作都受权限控制，关键操作需经审批，并全程记录以供审计。你可以从免费开源的 [LetKite Lite](https://github.com/letkite/letkite-lite) 开始，或访问 [letkite.com](https://letkite.com) 了解更多。
