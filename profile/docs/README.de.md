<h1 align="center">LetKite</h1>

<p align="center">
  <a href="https://github.com/letkite/.github/blob/main/profile/README.md">English</a> · <a href="https://github.com/letkite/.github/blob/main/profile/docs/README.zh.md">简体中文</a> · <a href="https://github.com/letkite/.github/blob/main/profile/docs/README.ja.md">日本語</a> · <a href="https://github.com/letkite/.github/blob/main/profile/docs/README.ko.md">한국어</a> · <a href="https://github.com/letkite/.github/blob/main/profile/docs/README.es.md">Español</a> · <a href="https://github.com/letkite/.github/blob/main/profile/docs/README.fr.md">Français</a> · <b>Deutsch</b>

**LetKite ist die Ausführungsschicht zwischen KI und Ihren Maschinen.** Roboter geben der KI Hände in der physischen Welt; LetKite gibt ihr Hände in der digitalen. Es ist ein Remote-MCP-Gateway, über das Claude und andere MCP-kompatible Assistenten Befehle ausführen, Dateien verwalten und Logs verfolgen können – über eine ganze Flotte von Servern, Fabrikanlagen und Smart-Home-Geräten hinweg. Sie fügen es einmalig als benutzerdefinierten Connector in Ihrem bestehenden KI-Abo hinzu, und jede Aktion unterliegt Berechtigungen, wird freigegeben, wo es darauf ankommt, und für Audits protokolliert. Starten Sie mit dem kostenlosen Open-Source-Projekt [LetKite Lite](https://github.com/letkite/letkite-lite) oder erfahren Sie mehr auf [letkite.com](https://letkite.com).
